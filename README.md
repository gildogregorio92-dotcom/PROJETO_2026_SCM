## 1. Apresentação

Este repositório foi organizado para demonstrar conceitos e práticas de Gestão de Configuração de Software utilizando Git e GitHub. O objetivo é centralizar artefatos, registrar alterações e facilitar o compartilhamento de versões entre os participantes de um projeto.

## 2. Objetivos

- Compreender o papel de um repositório remoto de artefatos.
- Organizar documentos e arquivos do projeto.
- Demonstrar o controle de alterações e o histórico de versões.
- Documentar comandos básicos do Git.
- Explicar como a colaboração pode ocorrer de forma controlada.

## 3. Estrutura do repositório

- `documentacao/gestao_de_configuracao.md`: conceitos, processo e benefícios.
- `documentacao/procedimentos_git.md`: comandos e fluxo de trabalho.
- `documentacao/equipe_e_responsabilidades.md`: papéis e colaboração.
- `registro_alteracoes.txt`: histórico descritivo das alterações dos artefatos.

## 4. Ferramentas

- **Git:** sistema distribuído de controle de versão.
- **GitHub:** serviço de hospedagem do repositório remoto e colaboração.
- **Git Bash ou terminal:** ambiente para executar os comandos Git.

## 5. Fluxo básico

1. Clonar o repositório remoto.
2. Criar ou editar um artefato.
3. Conferir as alterações com `git status`.
4. Preparar os arquivos com `git add`.
5. Registrar a versão com `git commit`.
6. Enviar as alterações com `git push`.
7. Conferir no GitHub se os arquivos foram publicados.

> **Nota sobre a atividade:** os arquivos desta estrutura constituem os artefatos iniciais de documentação. Para comprovar a execução prática no computador, o estudante ainda deve realizar os comandos indicados e inserir capturas de tela reais no relatório acadêmico.
